# 筏子溪工藝 DIY 互動教學 AR APP 專題企劃書

## 1. 專題名稱
**筏子溪工藝 DIY 互動教學 AR APP**（名稱暫定）

## 2. 問題背景
在工藝工作坊體驗中，傳統的平面說明書或真人示範影片存在視角被遮擋、無法任意旋轉觀看細節與縫隙卡扣等問題。這導致手作新手與小朋友在組裝時容易卡關，且高度依賴現場指導人員反覆示範，降低了體驗流暢度與樂趣。

## 3. 目標使用者
- **主要使用者：** 參加手作體驗的親子遊客（由家長持手機引導小朋友）與手作新手遊客。
- **使用情境：** 在工作坊現場桌面上，邊操作實體材料邊參考 AR 畫面，或搭配現場手機支架輔助使用。

## 4. 核心問題與解決方案
- **核心問題：** 平面 2D 畫面無法即時提供全視角的空間結構指引。
- **解決方案：** 透過 AR 圖片辨識技術，將 3D 模型與動態拆解步驟直接疊加於說明書卡片上，支援 360° 自由旋轉與縮放，協助使用者看清複雜構造。

## 5. AR 使用必要性
1. **空間視覺化：** 3D 虛擬零件與動態引導箭頭能直接標示組裝位置與卡扣方向。
2. **視角自主性：** 突破傳統影片的固定拍攝角度，提供自由旋轉與放大細節功能。
3. **動態拆解：** 5–10 秒的 3D 爆破拆解動畫比真人教學影片更加乾淨直觀。

## 6. 使用情境
- **地點：** 筏子溪工藝工作坊體驗區桌面。
- **操作方式：** 
  - 親子情境：家長操作手機查看 3D 分解步驟並導引小朋友進行實體組裝。
  - 個人情境：使用現場提供的手機支架固持手機，解放雙手進行組裝。

## 7. 核心功能與 MVP 範圍
- **MVP 範圍：** 聚焦於「單一紀念品」的完整多步驟分解流程。
- **核心功能：**
  - **Image Target 辨識：** 掃描說明書卡片觸發 3D 模型與 UI。
  - **3D 互動控制：** 單指 360° 旋轉、雙指縮放模型。
  - **步驟導覽介面：** 提供「上一步 / 下一步」按鈕切換不同組裝階段。
  - **視覺引導：** 動態箭頭與顏色光圈標示關鍵黏合/卡扣位置。

## 8. 使用者操作流程
1. 開啟 APP 並將鏡頭對準實體「說明書卡片」。
2. 系統完成辨識後，卡片上方出現對應的 3D 紀念品模型與當前步驟 UI。
3. 使用者播放短秒數動畫，觀察零件組合方式。
4. 使用手指旋轉或縮放模型，釐清背部或縫隙細節。
5. 完成該步驟組裝後，點擊「下一步」切換至後續階段，直至完成。

## 9. Figma 畫面規劃
- **AR 主掃描畫面：** 相機 Live View 區域，附有辨識框提示。
- **AR 互動 UI 疊層（HUD）：**
  - 頂部：當前步驟文字說明（例：步驟 2 - 底部卡扣固定）。
  - 底部控制區：「上一步」、「下一步」按鈕及「重設視角」按鈕。

## 10. Unity + Vuforia 技術實作規劃
- **引擎與 SDK：** Unity (C#) + Vuforia Engine。
- **辨識機制：** Vuforia Image Target（以說明書卡片印刷圖樣作為 Marker）。
- **邏輯控制：** 使用 C# 腳本管理 Animator 動態切換與 UI 步驟狀態機。

## 11. 所需素材
- **3D 模型與動畫：** 使用 Maya 製作紀念品拆解與組合模型及 keyframe 動態（或結合 AI 3D 工具生成後進行網格修正）。
- **2D 介面與圖示：** Figma 設計 UI 元素匯入 Unity 使用。
- **辨識圖（Target）：** 特徵點豐富的高對比說明書卡片圖檔。

## 12. 技術風險與縮減方案
- **風險 1：AI 3D 模型相容性問題**
  - *應對方案：* 若 AI 生成的模型網格過於複雜或拓撲混亂，改以 Maya 繪制基礎 Low-Poly 模型。
- **風險 2：現場光線影響 Vuforia 追蹤**
  - *應對方案：* 採用固定高對比卡片作為 Target，並在 UI 加入「鎖定 3D 模型」按鈕，即使相機暫時移開卡片也能繼續操作 3D 模型。

## 13. 測試與驗收標準
- **驗收方式：** 邀請同學與指導老師進行現場體驗測試。
- **成功指標：** 測試者可以在不依賴口頭提示的情況下，僅憑 AR 介面與 3D 視覺指引順利完成紀念品組裝。
